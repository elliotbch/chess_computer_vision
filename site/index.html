Vision d'échiquier : pièces inconnues

Les pièces sont remplacées par des marqueurs identiques (un par camp, des post-it par exemple) : seul le camp est visible. La démo déduit le type de chaque marqueur de ses seuls déplacements, coup par coup, même si l'observation commence en cours de partie, et sépare les pièces identifiées avec certitude des types seulement probables. Elle montre aussi l'étape de vision : trouver l'échiquier sur une photo et détecter les cases occupées.

Votre navigateur ne prend pas en charge WebAssembly : la démo ne peut pas s'exécuter ici. Essayez une version récente de Firefox, Chrome, Edge ou Safari.

Essayer : identifier les pièces inconnues coup par coup

Le moteur ne reçoit que l'occupation des cases (marqueur blanc, marqueur noir, vide) après chaque coup : ni les types, ni la position de départ, ni les droits de roque. Un marqueur dont tous les types sauf un sont exclus par les règles est identifié avec certitude (symbole de la pièce) ; sinon, la grande lettre suivie de « ? » donne le type le plus probable et la petite ligne les types encore possibles (R roi, D dame, T tour, F fou, C cavalier, P pion). Survolez un marqueur pour les probabilités.

    Comment ça marche

    • Calibration : les marqueurs colorés sont effacés par inpainting, puis findChessboardCornersSB d'OpenCV cherche les 7×7 coins intérieurs. Si une main cache une partie du plateau, une sous-grille plus petite est acceptée et sa position dans le plateau 8×8 est choisie en vérifiant l'alternance clair/foncé. Les pastilles rose et bleue donnent l'orientation (a1, a8).
    • Vue de dessus : une homographie projette le plateau sur une image de 800×800 (100 px par case).
    • Occupation : pour chaque case, écart de couleur entre le centre et le bord, saturation, densité de contours et contraste ; une régression logistique à 4 variables (ou un seuil adaptatif) décide vide / occupée ; la teinte du marqueur donne le camp.
    • Pièces inconnues : chaque marqueur est une variable dont le domaine est l'ensemble des types encore possibles. Chaque coup observé restreint le marqueur qui bouge (géométrie, sans saut sauf le cavalier ; pion : avance, double pas depuis sa 2e rangée, prise en diagonale, en passant, promotion ; le roque désigne le roi et la tour). S'y ajoutent des règles vraies dans toute position : un seul roi par camp, jamais de pion sur la 1re ou la 8e rangée, pions + pièces promues en surplus ≤ 8 (fous comptés par couleur de case), 32 marqueurs présents donc aucune promotion, le camp qui vient de jouer n'est pas en échec. Les exclusions se propagent (couplage marqueurs / pièces pour le dénombrement) : une certitude est une preuve, jamais un pari.
    • Le plus probable : pour les marqueurs encore ambigus, une régression logistique apprise sur 4 000 parties lichess (licence CC0), distinctes des parties de test, classe les types restants. Elle tient compte de la case actuelle du marqueur ; elle ne sert jamais aux certitudes.
